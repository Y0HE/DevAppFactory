# Factory workflow

- Work only inside this project folder.
- Read `docs/idea.md` and, when present, `docs/spec.md` before changing code. Acceptance criteria in the spec decide when a feature is done.
- Keep commits small and focused, with a message that says what changed and why.
- Commit locally only. Pushing, pull requests, merges and deploys are done by DevAppFactory or by the user.
- Never read or write `.env` files or other secrets. If a secret is needed, stop and ask.
- When something is blocked or unclear, stop and say so instead of guessing.
