# Accessible HTML

- Every page has one h1, a lang attribute and a descriptive title. Headings go down one level at a time.
- Use the element that means what you need: `button` for actions, `a` for navigation, `label` for every form control, lists and tables for lists and tables.
- Everything works with the keyboard alone, in a sensible order, with a visible focus indicator.
- Images have alt text (empty for decoration); links and buttons say where they go or what they do.
- Text contrast is at least 4.5 to 1. Colour is never the only way information is shown.
- Errors in forms are written next to the field and announced, not only shown in red.
