# Documentation

- A change that alters behaviour, commands, configuration, endpoints or setup updates the README and `docs/` in the same commit series.
- Write only what you checked. Every command, path and variable name in the docs exists as written.
- Remove text that is no longer true instead of adding a correction beside it.
- Document why a decision was taken where it is not obvious from the code. Do not restate the code.
- Environment variables are listed in `.env.example` with a safe placeholder and one line of explanation.
